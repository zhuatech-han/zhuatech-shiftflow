# 结构与事务边界

同源 Nginx 转发 /api 到 Spring Boot。服务使用服务端会话、CSRF、BCrypt和数据库实时权限；JPA validate 与 Flyway 保证实体和迁移结构一致。数据库密码由环境注入。生产 Clock.systemUTC()，可控时钟只在测试目录中提供。

## 时间与状态

Shift 为 DRAFT / PUBLISHED / CANCELLED。Coverage 为 REQUESTED → ACCEPTED → APPROVED，也可 REJECTED / WITHDRAWN / STALE。Unavailability 为 ACTIVE / CANCELLED。知悉是班次字段，替班批准后清空，计划时间结束不产生出勤状态。

跨午夜最长12小时；资格有效日期为上海日期、首尾日期包含，班次结束瞬间不占下一个日期。冲突使用半开区间，比较时取两个已发布计划较大的间隔；不可排班仅检查真实重叠。

## 写事务与并发

全部排班与后台管理变更先锁定基础部门1，再刷新当前账号和角色，在 READ COMMITTED 事务内验证权限和业务。不能删除基础部门1。统一入口序列化冲突判断和写入，避免两条冲突班次同时发布、或批准替班同时更改资格。实体版本作为客户端乐观保护。

业务 requestKey 对当前账号唯一，存储命令载荷 SHA-256、对象种类及ID；完全相同的重试返回当前对象，键被不同载荷使用返回409。业务事件与审计同事务提交，任何异常整体回滚。快照不可通过接口修改。草稿删除会移除其草稿事件及幂等索引，并记录删除审计；发布记录不能删除。

账号/角色/资格/岗位调整会重新核查所有未结束发布班次的有效性；取消/改派后活动替班失效。批准事务更新当前员工、指派修订、知悉字段、申请状态和事件。此设计没有分布式锁或多租户隔离，也没有压力测试指标；企业扩展前需重新评估锁粒度、目录规模、会话共享和审计保留。

查询列表在数据库分页；管理目录/岗位/资格/审计单次读取上限一万条。工作台适合小规模协作；大规模部署应提供有界待办查询与保留策略。统计最多一万条，超出返回 REPORT_LIMIT。权限目录的代码由系统注册，界面只修改名称；菜单隐藏不代替接口验权。
