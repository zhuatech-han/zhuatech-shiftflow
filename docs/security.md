# 安全与授权

账号认证使用BCrypt强度12、30分钟服务端会话、CSRF与单账号/IP连续8次失败后五分钟限制。账号禁用、密码或角色权限修改会在后续请求校验时生效；目录的密码哈希以JsonIgnore保护。会话标识在登录后更新，密码变更注销当前会话，其他旧密码会话也不能继续访问。

ALL查看全部；DEPARTMENT查看本部门；ASSIGNED只看本人已发布指派及已批准的原交接历史、本人参与的替班和本人不可排班。替班目标可查看该申请的班次资料以接受交接，但不能访问其他请求；资格读取按部门或本人限制。候选人仅返回姓名与ID，不返回不可排班正文、账号凭证或完整后台资料。

任何批准人不得是请求双方之一；发布、接受、批准和改派均实时检查条件。员工不能使用管理接口。请求输入不接受系统状态、密码哈希、确认时间等受控字段；版本/幂等保护用于处理旧页面和网络重试。查询值绑定，不拼接用户SQL。

仅提供自有JSON导出，没有文件上传或可变下载路径。测试资料均标记“验收测试”，不采集医疗证明、实际考勤、私人联系信息。实际部署须评估组织使用的排班资料权限、HTTPS、备份与数据保留；日志不公开，密钥只置于 .env 或外部密钥管理。安全反馈通过官网/微信私下联系并先脱敏。
